Website privacy

This page describes the website files currently delivered in this project workspace, not unverified hosting-provider behavior.

Scope limitation: The production host, server logs, DNS/CDN configuration, and third-party hosting behavior have not been inspected. Hosting may process request data; consult the operator and provider policies for those details.

What is present in these site files

The implementation is a static set of HTML and CSS pages with local artwork. There are no forms, accounts, embedded video, analytics scripts, advertising scripts, or cookie-setting JavaScript in the authored files inspected for this site. The navigation uses native HTML <details> and <summary> controls.

Pages include links to an external GitHub repository address supplied in the plan. Following external links takes you to that third-party service, whose privacy practices are separate.

What is not claimed

This page does not claim that the hosting provider or any network intermediary sets no cookies, retains no logs, or collects no data. Confirm the actual production configuration and applicable legal requirements with the site owner before launch.

Questions and updates

No verified privacy contact was provided. A responsible owner contact and a review of production hosting behavior are required before this notice can be considered complete.
