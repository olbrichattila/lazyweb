Privacy

Website privacy

This page describes requests authored in the website files, not unverified hosting-provider behavior.

Scope limitation: The production host, server logs, DNS/CDN configuration, and third-party provider behavior have not been inspected. Hosting may process request data; consult the operator and provider policies for those details.

What is present in these site files

The website is a static set of HTML and CSS pages with local artwork. The download page also loads a small browser-side script that optionally requests https://api.github.com's latest-release endpoint. It uses the response to refresh the displayed release version, supported asset links, release-page links, and SHA-256 digests. The request is bounded by a timeout. If it fails, times out, or returns incomplete data, the checked-in links and fallback content remain in place.

The authored files contain no forms, accounts, embedded video, analytics scripts, advertising scripts, or cookie-setting JavaScript. Navigation uses native HTML <details> and <summary> controls. Pages also link to GitHub and the site author's external website; following those links takes you to the respective third parties.

What is not claimed

This page does not make guarantees about data transmitted to GitHub, the hosting provider, or any network intermediary, or about cookies, logs, retention, or collection. The actual production configuration and applicable legal requirements have not been reviewed.

Questions and updates

No verified privacy contact was provided. A responsible owner contact and review of production hosting behavior are required before this notice can be considered complete.
