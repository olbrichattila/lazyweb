Download Lazy Coding Agent

Current release: 0.1.12. Installers and packages are built in CI and published on GitHub Releases. Pick your platform below or open the full releases page for older versions and release notes.

All releases on GitHub
Beta software — installers are not code-signed. Lazy Coding Agent is in beta. Packages are published without a vendor code signature, so Windows, macOS, Linux, or your browser may warn about an unknown publisher or untrusted download. You may need to explicitly accept that risk to install (for example SmartScreen on Windows, Gatekeeper on macOS, or security prompts when running an AppImage). Compare files against the SHA-256 checksums below when you can.

64-bit installer
