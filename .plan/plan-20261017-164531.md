# Replace the homepage hero logo with the transparent neon owl

## Goal
Replace the large owl artwork in the homepage hero with the user-provided transparent PNG, while preserving the existing small owl mark in the site header.

## Findings
- The large artwork is the hero image in `index.html` (`.hero-art`), currently referencing `assets/owl-mark.png` with a fixed 307×301 dimension declaration.
- The same `assets/owl-mark.png` is used for the small navigation brand mark across the site's HTML pages. It should remain unchanged so this is a hero-only visual replacement.
- The requested source image is present at `temp/Futuristic Neon Owl Emblem.png` (about 1.34 MB); it is currently untracked. Keep the original temporary file intact.
- Shared hero styling is in `assets/site.css`. `.hero-art` currently draws a border, gradient panel, rounded corners and shadow, and its image fills that framed area. Those treatments would obscure the requested transparent appearance if retained unchanged.
- The static integrity checker is `tools/check_site.py`; it verifies local asset paths and accessibility/metadata basics. No cached compiler diagnostics are available, and this static HTML/CSS change does not require a compiler.

## Proposed changes
1. Copy the supplied PNG from `temp/` into `assets/` under a concise, URL-safe filename such as `assets/neon-owl-emblem.png`. Do not rename, delete, or modify the temporary source.
2. Update only the homepage hero `<img>` in `index.html` to use the new asset. Replace the old fixed 307×301 dimensions with intrinsic/responsive sizing (for example `width="..."` only if confirmed against the PNG's actual dimensions; otherwise omit the stale dimensions and rely on CSS). Keep `fetchpriority="high"` and use descriptive alt text such as `Futuristic neon owl emblem for Lazy Coding Agent`.
3. Retain the header brand references to `assets/owl-mark.png`; do not replace all site logos or alter unrelated pages.
4. Adjust `.hero-art` presentation in `assets/site.css` so it no longer paints an opaque panel, border, or shadow behind the transparent art. Center the image and cap its rendered width to a sensible responsive maximum while preserving `height: auto` and the existing one-column mobile layout. Keep the hero grid and its surrounding spacing intact.

## Validation
- Run `python3 tools/check_site.py` and confirm all local links/assets and page checks pass.
- Review the homepage at desktop and narrow/mobile widths: confirm transparency reveals the page background, the artwork stays within the hero column without distortion or clipping, and the header mark remains small and unchanged.
- Verify the homepage hero references the new asset, while header logo references elsewhere still point at `assets/owl-mark.png`.
- Inspect the final diff to confirm only the intended hero markup/style and the copied image asset changed; do not commit or remove the temporary source as part of this task.
