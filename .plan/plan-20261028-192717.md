# Replace the home-page screenshot with `single-window.png`

## Goal
Convert the supplied `temp/single-window.png` screenshot to WebP and use the converted image in the screenshot section on the home page, without changing the separate screenshot used on the Features page.

## Findings
- The source image exists at `temp/single-window.png` (605,375 bytes).
- The home page screenshot is in `index.html` and currently references `assets/workspace-screenshot.webp`; the markup declares dimensions of 1024 × 774.
- `features.html` independently uses `assets/workspace-screenshot.webp`, so replacing that existing asset would also change the Features page. Keep it intact and create a distinct WebP for the home page.
- The home page image has descriptive alt text and a caption that should be revised to reflect the supplied screenshot rather than assumed to retain details from the old image.
- The site is static HTML/CSS with no package/build step. `tools/check_site.py` is the documented dependency-free site integrity check.

## Implementation plan
1. Convert `temp/single-window.png` into an optimized WebP asset at `assets/single-window.webp` using an available image conversion tool/library. Preserve the source PNG in `temp/`.
2. Read the converted asset's actual pixel dimensions and file size. Do not carry over the old image's hard-coded dimensions unless they match; update the image width/height attributes to the new dimensions to reduce layout shift.
3. In `index.html` only, change the screenshot image source to `assets/single-window.webp`. Update its alt text and figcaption to accurately describe only what is visible in the new screenshot; avoid guessing at UI elements not present.
4. Leave `features.html` and `assets/workspace-screenshot.webp` unchanged so the Features page retains its current screenshot.
5. Verify the new file is a valid WebP, the home page references the new local asset, the Features page still references the existing screenshot, and the site integrity checker passes. Review the resulting diff to confirm the change is limited to the new image asset and home-page markup.

## Acceptance criteria
- `assets/single-window.webp` is generated from `temp/single-window.png` and decodes as WebP.
- `index.html` displays the new asset with matching dimensions and accurate alternative text/caption.
- The existing Features page screenshot and its asset remain unchanged.
- Local-link/site integrity checks pass.
